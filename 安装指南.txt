llama.cpp Router 后台常驻 - 中文使用说明
========================================

一、本工具是什么
---------------
把 llama.cpp 的 router 模式（一个 llama-server 实例托管多个模型，
请求里指定 model 名就自动切换）封装成 Windows 后台服务：
  * 开机自启
  * 崩溃自动重启
  * 关闭终端窗口不影响运行
  * 空闲 N 秒自动卸载模型释放显存

二、文件清单
-----------
config.json            唯一配置数据源（UI 与 ini 都从这里派生）
router-preset.ini      由 config.json 自动生成（请勿手工改）
manager-ui.bat         【推荐入口】双击打开可视化界面
install-router.bat     一键安装为后台服务（需要管理员）
uninstall-router.bat   卸载后台服务（需要管理员）
router-run.bat         前台运行（测试用，关闭窗口即停）
status-router.bat      查看服务状态 + 最近日志
test-router.bat        测试所有启用模型的切换
*.py                   业务逻辑（不用关心）
安装指南.txt           本文件

三、第一次安装（拷贝到新电脑后的步骤）
-------------------------------------
0. 确认本机已安装 Python 3.8 或更高版本
     - cmd 中执行:  py --version
     - 没有的话到 https://www.python.org 下载安装
     - 安装时勾选 "Add python.exe to PATH"
     - 备注：tkinter 是 Python 自带的，无需额外安装

1. 把本文件夹放在任意位置（建议放到纯英文路径下，
   避免和系统路径有冲突）

2. 双击 manager-ui.bat 打开可视化界面
     - 如果弹「需要管理员」就右键 → 以管理员身份运行
     - UI 会自动检查环境并提示问题

3. 在 UI 中：
     a) 「全局」页：检查 llama_dir 是否指向你的 llama.cpp 目录
        （含 llama-server.exe 的那个目录）
     b) 「全局」页：按需调整端口、空闲卸载时间等
     c) 「模型」页：增删改模型条目；可以填多模态 mmproj 路径；
        推测解码用「启用推测解码」勾选开启，草稿文件可选
     d) 切到「服务」页 → 点「安装服务」
     e) 等待「服务已安装并启动」

4. 浏览器访问  http://127.0.0.1:8080/v1/models
   看到模型列表即为成功。

四、日常使用
-----------
* 改配置后 → UI「服务」页 → 点「重启」即生效
* 临时停服务 → UI「服务」页 → 点「停止」
* 卸服务   → 双击 uninstall-router.bat（管理员）
* 看日志   → UI「服务」页底部日志框，或 status-router.bat
* API 调用：base_url  = http://127.0.0.1:8080/v1
           model     = 配置里每个模型的 alias 字段
* 命令行测试：双击 test-router.bat

五、模型设置
-----------
在「模型」页，每个模型有：
  * ID          段名（英文+短横线），API 中通常用不到
  * alias       API 请求里填的 model 名，简洁好记
  * model       主模型 .gguf 绝对路径
  * mmproj      多模态投影文件（视觉模型需要）
  * 推测解码    勾选「启用推测解码」独立开关
  * 草稿模型    MTP/DFlash 草稿 .gguf 路径（可选：模型自带
                草稿权重时留空）
   * 草稿类型    留空按文件名猜 (mtp-/dflash-/dspark-)，
                 也可手动选 draft-mtp / draft-dflash 等；
                 无草稿文件时必须手动选类型
   * 启用        取消勾选 = 不加入 preset.ini（暂不用）
   * 参数子表    每个参数有「启用开关 + 值」两个控件：
                 启用 + 填值 → 才会写入 ini
                 取消启用 → 该参数不写入，沿用 llama.cpp 默认
    * 草稿高级参数  草稿面板底部「高级 (可选)」六项，各自带勾选框：
                  spec-draft-device / threads / threads-batch /
                  type-k / type-v / backend-sampling
                  勾选 + 填值 → 才写入 ini；不勾就不写，
                  草稿总开关关闭时一律不写入（设置保留）
    * 推测类型    草稿面板里的「推测类型」= spec-type，
                  参数子表不再重复出现（子表那份会被面板值覆盖）
    * 快捷参数勾选  草稿面板里直接显示的 7 项，每项自带勾选框：
                  草稿模型 .gguf / 推测类型 / n-max / n-min /
                  p-split / p-min / 草稿 GPU 层数
                  勾选 → 才写入 preset.ini；取消勾选 → 这行彻底不写，
                  且该项控件自动置灰。设置保存在模型配置里，
                  重新选中该模型会原样回读。老配置默认全部勾选，
                  与升级前的输出完全一致。

六、显存与空闲策略
----------------
空闲卸载时间：「全局」页 → 空闲 N 秒后自动卸载，默认 3600 (1 小时)。
llama-server 到点会调用 sleep，把模型从显存卸载到 RAM（保留 KV），
来新请求时自动唤醒。第一次唤醒可能要几秒加载回显存。

模型切换时的提前卸载：llama.cpp router 模式已经内置，**你不需要配置**。
每次请求指定不同 model 名时，旧模型会被自动腾出 slot 给新模型。

显存被其他程序抢占：可选启用 watchdog 守护。
  1.「全局」页 → 显存守护 watchdog → 勾选启用
  2. 设置阈值（如 2048 MB = 2GB）、检测间隔（如 10 秒）
  3. 切到「服务」页 → 点「安装 watchdog」
  watchdog 会定期查 nvidia-smi，低于阈值时主动
  POST /models/unload 卸载最久未用的模型，为其它程序腾显存。
  注意：watchdog 依赖 nvidia-smi（NVIDIA 驱动自带），需在 PATH 中。

七、常见问题
-----------
Q1: 提示「需要管理员权限」
A1: 以管理员身份运行 manager-ui.bat；或者只通过 UI 改配置，
    改完保存后右键 install-router.bat → 以管理员身份运行。

Q2: 改了配置不生效
A2: router-preset.ini 改了之后必须重启服务才会被 llama-server
    重新读取。UI「服务」页 → 「重启」一键搞定。

Q3: 提示找不到 llama-server.exe
A3: 在「全局」页把 llama_dir 改成你安装 llama.cpp 的根目录，
    该目录下要有 llama-server.exe 文件。

Q4: 想两个模型同时驻留
A4: 「全局」页 models-max 改 2（显存够时才建议）。

Q5: 全部走 GPU
A5: 「全局」页「可选参数」区，勾上 n-gpu-layers，填 99 或 auto。

Q6: 启动时弹窗说「服务无法启动」
A6: 多半是端口被占或模型路径错。先看「服务」页底部日志
    或 C:\llama.cpp\logs\router.err.log 里的真实原因。

Q7: Python 报错 No module named 'tkinter'
A7: Windows 重新跑一次 Python 官方安装包，确保 tcl/tk 组件
    被勾选。Linux: apt install python3-tk

Q8: 想要 UI 没有的高级参数
A8: 任何 llama-server 支持的 CLI 参数都可以加到 config.json
    的 model.params 里 (key 要和 CLI 一致
    如 spec-draft-n-max)，并在 UI 里勾选启用。
    注意：保存时 UI 会用本机 llama-server --help 核对一遍，
    本机版本不认识的 key 会被自动跳过不写入 ini（日志里会列出）。
    这是有意的 —— 一个不认识的 key 会让整个 router-preset.ini
    解析失败，所有模型都加载不了。

Q9: 保存后日志提示「本机 llama-server 不支持以下参数」
A9: 你的 llama.cpp 版本较老，还没编译进这些参数（如 n-cpu-ffn、
    lazy-mode）。它们已从 preset 里跳过，其余参数不受影响。
    升级 llama.cpp 后重新保存即可恢复写入。

Q10: 其它程序需要 GPU 显存时怎么办
A9: 三层机制按优先级：
    ① 启用 watchdog 守护：「全局」→ watchdog → 启用 → 「服务」→ 安装 watchdog
    ② llama.cpp router 自身：切换模型时旧模型自动腾 slot
    ③ sleep-idle-seconds：空闲到点自动 sleep 释放显存
    ④ 手动：UI「服务」页 → 停止 / 卸载 llama-router，把显存让给别的程序

八、打包分发给别人的方法
--------------------
A) 推荐：打成 zip 直接发
   整个文件夹压缩成 zip → 别人解压到任意目录 → 装 Python → 双击 manager-ui.bat
   优点：体积小、跨机器、免安装、可改源码。
   缺点：对方需要自己装 Python。

B) 进阶：PyInstaller 打成单 exe
   pip install pyinstaller
   pyinstaller --noconfirm --onefile --windowed ^
       --add-data "config.json;." ^
       --add-data "安装指南.txt;." ^
       --add-data "router-preset.ini;." ^
       --name llama-router-ui ui.py
   产物 dist/llama-router-ui.exe 单文件可双击运行（不需对方装 Python）。
   缺点：体积大（~15 MB）、杀软可能误报、首次启动慢。

C) 安装包：NSIS / Inno Setup
   完全图形化向导式安装，适合给完全不懂电脑的人用。工作量大。
   如果真要：建议先用 B) 的 exe 跑通，再让 NSIS 包成 .msi/.exe。

九、卸载
-------
双击 uninstall-router.bat（管理员），即可彻底删除 Windows 服务。
config.json 和模型文件不会被删，下次想用再 install 即可。
